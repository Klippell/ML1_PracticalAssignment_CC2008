## Objetivos do Projeto

* [cite_start]Compreender o funcionamento teórico e empírico de um algoritmo de ML[cite: 7].
* [cite_start]Implementar um algoritmo de classificação "do zero" (sem bibliotecas como scikit-learn)[cite: 16].
